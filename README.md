黄金矿工游戏 - 项目说明文档
一、项目介绍
这是一个基于 Java Swing 开发的经典黄金矿工小游戏，包含核心的挖矿抓取、关卡进阶、积分计算、背景音乐播放等功能，玩家通过鼠标操作控制钩子抓取金矿 / 石块获取积分，达到关卡目标即可通关，超时未达成则游戏失败。
二、技术栈
开发语言：Java（JDK 1.8+）
图形界面：Swing + AWT
音频处理：javax.sound.sampled（Clip）
开发工具：IntelliJ IDEA（项目配置文件适配 IDEA）

四、核心功能说明
1. 游戏流程
初始状态：游戏未开始，显示 “准备开始” 提示
开始游戏：右键点击启动游戏，倒计时 30 秒开始
游戏中：
钩子自动左右摇摆，左键点击发射钩子
钩子抓取金矿 / 石块后收回，获得对应积分
药水功能：右键使用药水（共 3 瓶），可忽略金矿重量 / 直接消除石块
关卡进阶：
每关目标积分为 关卡数*15，达成则进入商店（可购买药水），否则游戏失败
目前支持 2 关，通关 2 关则显示 “成功”
重新开始：失败 / 通关后左键点击可重置游戏
2. 核心类职责
类名	 核心职责
GameWin	窗体初始化、鼠标事件监听、画面重绘、关卡切换逻辑
Bg	背景绘制、积分 / 时间 / 关卡显示、音乐播放控制、游戏状态（失败 / 成功）展示
Line	钩子的摇摆、发射、收回逻辑，碰撞检测（抓取金矿 / 石块），药水效果处理
Gold/Rock	金矿（小 / 中 / 大）、石块的属性定义（坐标、大小、积分、重量）
Object	所有游戏实体的基类，封装坐标、尺寸、图片、碰撞矩形等通用属性 / 方法
MusicPlayer	音频加载、播放（循环）、暂停、停止的工具类
五、运行说明
1. 环境准备
安装 JDK 1.8 及以上版本
确保开发工具（IDEA/Eclipse）配置好 Java 环境
2. 资源准备
在项目根目录创建imgs文件夹
放入所需的图片（jpg/png/gif）和音频（wav）文件（文件名与代码中一致）
3. 启动方式
直接运行GameWin.java中的main方法
游戏窗口弹出后，右键点击开始游戏
六、操作说明
  操作	    功能
右键点击	开始游戏 / 使用药水
左键点击	发射钩子 / 重新开始游戏
商店界面	左键购买药水，右键返回游戏
七、注意事项
音频文件仅支持wav格式，若使用其他格式需修改MusicPlayer的音频解析逻辑
图片资源的路径需与代码中Toolkit.getDefaultToolkit().getImage("imgs/xxx")一致
游戏窗口大小为 768*1000，建议保持资源比例适配该尺寸
若出现图片 / 音频加载失败，检查文件路径和文件名是否大小写一致（Windows 忽略大小写，Linux/Mac 区分）
